## 2024-10-15 - [CRITICAL] Internal Network Evasion via IPv6 Mappings
**Vulnerability:** The application was vulnerable to Server-Side Request Forgery (SSRF) due to inadequate validation of URLs containing IPv4-mapped IPv6 IP evasion payloads (e.g., `::ffff:127.0.0.1`) and bracketed IPv6 URLs. The naive string matching failed to recognize these as internal IP addresses.
**Learning:** Standard library domain resolution and URL parsing methods often do not automatically unmap IPv4-mapped IPv6 addresses to their underlying IPv4 state for validation against IPv4 rulesets. Also, `url.host_str()` retains brackets for IPv6 addresses which breaks standard socket resolution.
**Prevention:** Always unmap mapped IPv6 aliases into their true IPv4 underlying state prior to blocklist checks using `to_ipv4_mapped()`. Ensure URL parsing logic explicitly trims brackets from extracted hosts before domain resolution. Replace naive regex/string checking with a centralized, robust network validator.
